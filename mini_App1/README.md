
## Getting started

This skeleton was created without the Flutter SDK/native platform
scaffolding (android/, ios/, web/, etc.), since those are generated by the
`flutter` CLI itself. To finish setting it up on your machine:

1. Make sure Flutter is installed: https://docs.flutter.dev/get-started/install
2. From the parent directory of this project, run:
   ```bash
   flutter create --project-name mini_app1 .
   ```
   Running `flutter create .` inside this folder regenerates the missing
   platform folders (android/, ios/, web/, linux/, macos/, windows/) without
   touching the lib/, test/, or pubspec.yaml files already here.
3. Install dependencies:
   ```bash
   flutter pub get
   ```
4. Run the app:
   ```bash
   flutter run
   ```

## Notes

- Uses Material 3 with a seeded color scheme (light + dark themes).
- `flutter_lints` is wired up in `analysis_options.yaml`.
- The `services/` and `models/` folders contain minimal placeholders to show
  where data/business logic should live as the app grows.
